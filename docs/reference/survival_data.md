# Survival data as example data for survival_plot function.

Survival data as example data for survival_plot function.

## Usage

``` r
data(survival_data)
```

## Format

Dataframe: survival record data (1st-col: Time, 2nd-col: Status,
3rd-col: Group).

## References

https://github.com/BioSciTools/BioSciToolsDatasets/tree/main/SurvivalAnalysis/
