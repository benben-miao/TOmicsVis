# Add subtle shadow effect to points

Add a soft shadow/glow effect to scatter plot points (simplified
version)

## Usage

``` r
add_point_shadow(p, shadow_color = "#00000020", shadow_size = 1.2)
```

## Arguments

- p:

  ggplot object: the plot

- shadow_color:

  Character: shadow color. Default: "#00000020"

- shadow_size:

  Numeric: shadow size multiplier. Default: 1.2

## Value

Enhanced ggplot object
