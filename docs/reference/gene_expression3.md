# Shared DEGs of all paired comparisons in all groups expression dataframe of RNA-Seq.

Shared DEGs of all paired comparisons in all groups expression dataframe
of RNA-Seq.

## Usage

``` r
data(gene_expression3)
```

## Format

Dataframe: Shared DEGs of all paired comparisons in all groups
expression dataframe of RNA-Seq. (1st-col: Genes, 2nd-col~n-1-col:
Groups, n-col: Pathways).
