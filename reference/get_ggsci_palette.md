# Get ggsci color palette (hex colors)

Get actual hex color values from ggsci palette

## Usage

``` r
get_ggsci_palette(pal_name = "Sci_AAAS", n = 10, alpha = 1)
```

## Arguments

- pal_name:

  Character: ggsci palette name

- n:

  Numeric: number of colors to return

- alpha:

  Numeric: transparency (0-1)

## Value

Character vector of hex colors
