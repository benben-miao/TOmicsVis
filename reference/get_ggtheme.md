# Get ggplot2 theme by name

Get ggplot2 theme object by theme name with enhanced customization

## Usage

``` r
get_ggtheme(theme_name = "theme_publication", base_size = 12)
```

## Arguments

- theme_name:

  Character: theme name

- base_size:

  Numeric: base font size. Default: 12

## Value

Theme object
